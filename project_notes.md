# Project notes

This academic team project was completed in 2025. My contribution focused on the Simcenter Amesim simulation and the main engineering analysis, including MATLAB post-processing. Another team member developed the Python route visualization.

The simulation used a provided Amesim base model. The model package and generated build/results files are excluded from this repository.

The MATLAB scripts use relative paths and descriptive variable names while preserving the original calculation methodology. The weather exports are stored as CSV files with descriptive headers. Reported summaries retain their original values; the differences from the supplied exports and the remaining validation steps are documented in the README.
